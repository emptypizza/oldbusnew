# oldbusnew

**종점 뒤에, 새로운 시작.** 대한민국 퇴역 버스 시장을 숫자와 시각 자료로 설명하는 한국어 리서치 홈페이지입니다.

크림색·짙은 녹색의 화면, 직접 제작한 버스 SVG 일러스트, 출처를 연결한 데이터 시각화로 구성했습니다. 프레임워크와 외부 실행 의존성 없이 HTML·CSS·JavaScript로 동작합니다.

![oldbusnew 홈페이지](docs/preview-home-2026-10-27.jpg)

## 화면 구성

- **시장 한눈에:** 2026년 7월 말 버스 보유 현황 도넛 차트와 2025년 승합차 폐차 실적. 집계 대상과 기간을 별도로 표시합니다.
- **버스의 다음:** 국내 중고 운행, 해외 수출, 부품·금속 회수, 공간 활용의 네 경로를 선택해 조건을 확인합니다.
- **가격 살펴보기:** 폐차 매입견적 6건, 중고 판매 호가 5건, 공공 매각 예정가 2건을 탭으로 구분합니다. 실제 거래가나 시장 평균으로 표시하지 않습니다.
- **활용 가이드:** 차량 서류·설치 부지·공사비 확인사항, 초기 비용 합산 도구, 자주 묻는 질문.
- **데이터와 출처:** 조사 기준과 원문 링크, 전체 JSON 다운로드.

모바일 메뉴, 키보드 탭 조작, 본문 바로가기, 모션 감소 설정, 인쇄 스타일을 지원합니다. 계산기 입력은 브라우저 안에서만 처리하며 저장하거나 전송하지 않습니다.

## 실행과 빌드

Node.js 20 이상이 필요하며, 별도 패키지를 설치할 필요는 없습니다.

```sh
npm run check
npm run build
```

`dist/`에 정적 배포 파일이 생성됩니다. 로컬에서 확인하려면 HTTP 정적 서버로 `dist/`를 제공하세요. 예를 들어 Python이 있다면:

```sh
python -m http.server 8080 --directory dist
```

파일을 직접 `file://`로 열면 브라우저의 로컬 파일 접근 제한으로 JSON 가격 데이터를 읽지 못할 수 있습니다.

## GitHub Pages

루트의 `index.html`과 상대 경로 자산만으로 서비스할 수 있습니다. 별도 빌드 없이 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)** 를 선택하면 됩니다. `.nojekyll`이 포함되어 있습니다.

저장소 코드를 공개하는 것과 GitHub Pages를 활성화하는 것은 별개의 설정입니다. Pages 설정이 꺼져 있으면 코드 반영만으로 공개 홈페이지 주소가 생성되지는 않습니다.

## 파일 안내

| 파일 | 역할 |

## 데이터 갱신 원칙

조사 기준일은 **2026-10-27**입니다. 자료의 집계 시점은 각각 다릅니다.

1. `content/research-data.json`의 수치, 게시일, 자료 기준일, 원문 URL을 함께 갱신합니다.
2. HTML에 기본 표시되는 보유·폐차 수치와 최초 가격 탭도 같은 자료로 갱신합니다. 차트 비중과 범례가 원자료와 일치하는지 확인합니다.
3. 보유 대수는 재고, 폐차 실적은 연간 흐름입니다. 서로 더하거나 폐버스 교체율로 계산하지 않습니다. 승합차 통계에는 소형 승합차도 포함됩니다.
4. 견적·호가·예정가격을 구분하고, 사례 범위를 전국 평균 시세처럼 표현하지 않습니다. 공공 폐차 조건 매각은 그대로 재사용할 수 있는 중고 매물과 다릅니다.
5. 매물 목록은 바뀔 수 있습니다. 게시일과 차종·연식·주행거리를 함께 기록하며, 판매 완료나 거래 성사 여부를 확인한 것으로 표현하지 않습니다.
6. `npm run check`와 `npm run build`를 실행한 뒤 데스크톱·모바일에서 차트와 버튼을 확인합니다.

이 프로젝트는 정보 제공을 위한 리서치이며 차량 거래를 중개하지 않습니다. 실제 등록·수출·해체·설치 가능 여부는 차량, 계약, 부지 조건과 현행 제도에 따라 확인해야 합니다.
